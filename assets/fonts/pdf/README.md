# PDF fonts (OFL)

Same families as the site (`app/layout.tsx`): **Instrument Serif** and **DM Sans**.

- `InstrumentSerif-*.ttf` — Instrument Serif (OFL)
- `DMSans-*.ttf` — DM Sans static latin cuts (OFL), same as [@fontsource/dm-sans](https://fontsource.org/fonts/dm-sans)

Used by `@react-pdf/renderer` via `lib/pdf/register-pdf-fonts.ts`.
